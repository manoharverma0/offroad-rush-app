# OFFROAD RUSH - APK build
1. Create a new GitHub repo, upload ALL files in this folder (keep the .github folder).
2. Open the repo > Actions tab > "Build APK" > wait ~5 min (it runs on push automatically).
3. Open the finished run > Artifacts > download OFFROAD-RUSH-apk > unzip > app-debug.apk
4. Copy the APK to your Android phone and install (allow "install unknown apps").
Game code lives in www/index.html.
